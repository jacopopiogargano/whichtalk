# Security

Please report security problems privately: open the repository's **Security** tab and choose
**Report a vulnerability**. Do not open a public issue for them.

WhichTalk is a static site with no server and no accounts. In scope: the published site in
`docs/`, the app in `src/`, and the build in `whichtalk/`, for example conference data or a
scraped page that could put script into a built page, or a way to read another conference's
saved plan. Reports are answered as soon as possible.
